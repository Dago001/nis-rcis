## 2. Process Lifecycle & Restart Rules

> [!CAUTION]
> Do NOT use `nohup node server.js &` on port 30898 for normal operation. The web server uses **CloudLinux Passenger**, which manages Node workers via sockets.

### How to Restart the Application:
Passenger pools Node workers in memory and caches them. Whenever code, assets, or configs are updated, trigger a reload via:
```bash
cd /home/nimcosel/domains/rcis.nimcoselection.com/public_html/frontend
mkdir -p tmp && touch tmp/restart.txt
```
Passenger detects `tmp/restart.txt` and reboots clean workers with zero downtime.

## 3. Server Bootstrap (`server.js`) & Environment Variables

Next.js standalone builds do **not** automatically read `.env` files in production. If environment variables are missing, Next.js throws `Error: Missing environment variable OAUTH_APPLICANT_CLIENT_ID` and returns HTTP 500.

> [!CAUTION]
> **DO NOT hardcode or override `process.env.PORT` in `server.js`.**
> CloudLinux Phusion Passenger dynamically assigns its own unix domain socket or internal port to Node. Overriding `process.env.PORT` prevents Passenger from communicating with the worker, which causes continuous spawn retries that exhaust the account's CloudLinux NPROC process limit and trigger HTTP 503.
> Keep `const currentPort = parseInt(process.env.PORT, 10) || 3000` as generated by Next.js standalone. Environment variables are loaded cleanly via `.env.production` placed in the app root.

## 7. PHP 8.4 & LiteSpeed Invariants (`request_parse_body`)

- **Root Cause Discovered:**
  - On CloudLinux ALT-PHP 8.4, the core PHP 8.4 function `request_parse_body()` is disabled or missing from the build.
  - Symfony `HttpFoundation\Request` in PHP >= 8.4 calls `request_parse_body()` on all HTTP `PUT`, `PATCH`, and `DELETE` requests.
  - Without a fallback polyfill, every draft save (`PUT /api/v1/applicant/draft`) or delete crashed with `Fatal error: Call to undefined function request_parse_body()`, returning `HTTP 500`.
- **Permanent Solution:**
  - `laravel.php` and `backend/public/index.php` must include the fallback polyfill:
    ```php
    if (!function_exists('request_parse_body')) {
        function request_parse_body(?array $options = null): array {
            return [$_POST, $_FILES];
        }
    }
    ```

## 8. Document & Image Storage Routing (`.htaccess`)

- **Signed URLs:**
  - Laravel issues short-lived signed URLs for applicant photos, captured signatures, and uploaded supporting documents via `Storage::disk('local')->temporaryUrl(...)`.
  - These URLs are formed under the path: `https://rcis.nimcoselection.com/storage/{path}?expires=...&signature=...`.
- **Permanent Invariant:**
  - `/home/nimcosel/domains/rcis.nimcoselection.com/public_html/.htaccess` must include:
    ```apache
    RewriteRule ^storage/(.*)$ laravel.php [QSA,L]
    ```
  - Without this rule, requests to `/storage/...` bypass Laravel and get intercepted by CloudLinux Passenger / Next.js, resulting in 404 errors and broken image previews.

## 12. Biometric Data Encryption & Database Integrity

- **Database Column Types:**
  - `applications.fingerprints` and `applications.fingerprint_template` must remain `LONGTEXT NULL` to accommodate AES-256 encrypted multi-fingerprint JSON templates exceeding standard MySQL `TEXT` (65KB) limits.
- **Defensive Decryption Guard (`fromEncryptedString`):**
  - `Application.php` must maintain the overridden `fromEncryptedString($value)` method with a `try...catch (\Illuminate\Contracts\Encryption\DecryptException $e)` wrapper.
  - This ensures that if any malformed or legacy corrupted encrypted payload is loaded, it logs a warning and returns `null` rather than throwing an uncaught 500 error across dashboard and queue views.

## 13. Next.js Shared Hosting Performance & Navigation Invariants

- **Navigation Prefetching (`prefetch={false}`):**
  - High-density navigation sidebars (such as `StaffShell.tsx`) must set `prefetch={false}` on all `<Link>` components.
  - On CloudLinux Phusion Passenger with constrained Node.js thread pool allocations (`UV_THREADPOOL_SIZE: 2`), eager prefetching fires up to 14 simultaneous RSC network requests, choking the worker process queue and producing 5+ second navigation delays. Disabling background prefetch ensures immediate click responsiveness.
